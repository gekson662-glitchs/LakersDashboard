# Lakers 2026/27 Ultra HQ

Public, static Lakers analytics dashboard. The site is served from `index.html` via GitHub Pages.

## Enable GitHub Pages

1. Open the repository Settings.
2. Select **Pages** in the Code and automation section.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.

Once the Pages deployment completes, the site will be available at `https://gekson662-glitchs.github.io/LakersDashboard/`.
